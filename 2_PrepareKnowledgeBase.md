# 2. Подготовка базы знаний

## Выбор предметной области

В качестве предметной области буду использовать посты из телеграм канала (это мой канал) [t.me/nice_ipa](https://t.me/nice_ipa). В используемых моделях LLM данные из этого канала точно не использовались.

## Выгрузка данных

Экспорт канала в Telegram:
1. Открыть канал в Telegram Desktop.
2. Нажать на три точки (меню) в правом верхнем углу канала.
3. Выбрать «Экспорт истории чата» (Export chat history).
4. В настройках выбрать, что экспортировать: «Сообщения», «Фотографии».
5. Выбрать формат (JSON) и период (за все время).
6. Нажать «Экспортировать» и указать папку для сохранения. 

## Подготовка документов

1) Указать путь для параметров скрипта `INPUT_JSON`, `OUTPUT_DIR`.

2) Выполнить скрипт [/data/2_rawdata_parser.py](/data/2_rawdata_parser.py):

```bash
python ./data/2_rawdata_parser.py
```

Скрипт выведет:
```
>>>>> Готово. Извлечено постов: 132
>>>>> Посты сохранены в папке: ./data/knowledge-base/posts
```
