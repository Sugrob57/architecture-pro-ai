# 4. Реализация RAG-бота с техниками промптинга

## Настройка

### 1. Доустановить пакеты

```bash
pip install requests
```

### 2. Подготовить ENV-переменные для авторизации в облачной LLM (используется YandexGPT)

1. Шаг 1. Зарегистрируйтесь в Yandex Cloud
    - Перейдите на [.](https://console.cloud.yandex.ru/)
    - Войдите с Яндекс‑аккаунтом или создайте новый.
    - Примите условия использования и активируйте облако.
2. Шаг 2. Создайте платёжный аккаунт (если требуется)
    - В консоли перейдите в Billing (меню слева).
    - Создайте платёжный аккаунт и привяжите карту (для активации гранта может не потребоваться).
3. Шаг 3. Получите идентификатор каталога (folder ID)
    - В консоли перейдите в раздел Облака и каталоги.
    - Выберите нужный каталог (например, default).
    - Скопируйте ID каталога — он виден в адресной строке или на странице каталога.
4. Шаг 4. Создайте сервисный аккаунт и API‑ключ
    - В разделе Сервисные аккаунты нажмите Создать сервисный аккаунт.
    - Назначьте роль: ai.languageModels.user (достаточно для вызова API).
    - После создания аккаунта перейдите в него и нажмите Создать ключ → API‑ключ.
    - Скопируйте сгенерированный ключ — он понадобится в скрипте.
5. Шаг 5. Настройте переменные окружения
    - В терминале (Linux/macOS) или командной строке (Windows) задайте переменные:
        export YANDEX_API_KEY="ваш_api_ключ"
        export YANDEX_FOLDER_ID="ваш_id_каталога"

## Реализация RAG-pipeline

### Описание алгоритма

Для реализации RAG-pipeline подготовлен скрипт [/data/4_rag_console_client.py](/data/4_rag_console_client.py).

```bash
python ./data/4_rag_console_client.py
```

Данный скрипт запускает консольное приложение, которое готово принимать текстовые запросы, и обрабатывать их.
Обработка выполняется по следующему алгоритму:
1. Загружается ранее созданный индекс (CromaDB)
2. Текст запроса преобразуется в векторное представление (embedding), используя ту же модель (`intfloat/multilingual-e5-large`), что была при формировании индекса.
3. Выполняется поиск топ4 наиболее близких векторов в индексе (чанков).
    - если чанки не найдены - сразу ответ пользователю что ничего по запросу не известно.
4. Формируется промпт для LLM. Промпт обогащается системными текстами:
    ```
    Ты — эксперт по крафтовому пиву и немного по другим напиткам тоже.
    Используй ТОЛЬКО информацию из источников ниже.
    Если вопрос про конкретное название - отвечай по формату, указанному ниже.
    Если вопрос про вкусовые качества - приведи примеры, пиши все размышления по теме.
    Если информации недостаточно — честно скажи об этом.

    ФОРМАТ ОТВЕТА:
    1. Описание сорта
    2. Ссылка

    ПРИМЕР ОТВЕТА:
    Q: Что можешь рассказать про punk ipa?
    A: Punk IPA — это популярный сорт крафтового пива. Его можно встретить в барах на кранах разливного пива практически в любом городе. 
    Подробнее смотри по ссылке: https://t.me/nice_ipa/115

    ---

    ИСТОЧНИКИ:
    [Источник 1]
    {текст}
    (Ссылка: {ссылка на пост в telegram})

    ...

    [Источник 4]
    {текст}
    (Ссылка: {ссылка на пост в telegram})

    ВОПРОС:
    {query}

    ОТВЕТ:
    ```
5. В LLM отправляется промпт (используется "`yandexgpt-lite`")
6. Ответ LLM вывыдится в консоль
